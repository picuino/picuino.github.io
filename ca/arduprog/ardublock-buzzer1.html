6. Exercicis amb el timbre¶

Programa els blocs necessaris per resoldre els problemes següents.

  1. El programa següent emet un to de 1000Hz amb una durada de 200ms cada segon. Modifiqueu el programa per emetre un to de 1500Hz amb una durada de 400ms cada dos segons.

  2. El programa següent emet una sèrie de notes ràpides cada dos segons a l'escala 4. Modifiqueu el programa per emetre una altra sèrie de notes diferents a l'escala 5.

  3. El següent programa toca l’inici de la cançó de feliç aniversari. Completa el programa amb la cançó completa sabent que les notes són les que apareixen a la taula següent. La durada de les notes serà de 200, 400 o 800 mil·lisegons.

    No es poden enviar de nou més de 16 notes. Cada nou enviament ha d’esperar que la puntuació anterior acabi de sonar.

    Notes de feliç aniversari:

    `` Do4 do4 re4 do4 fa4 mi4 ''`
    `` Do4 do4 re4 do4 sol4 fa4 ''`
    `` Do4 do4 do5 la4 fa4 mi4 re4```
    `` Do5 do5 la4 fa4 sol4 fa4 ''`

  4. Repetiu l'exercici anterior amb la música de la panerola:

    `` Do4 do4 do4 fa4 la4 ''
    `` Do4 do4 do4 fa4 la4 ''
    `` FA4 FA4 MI4 MI4 RE4 RE4 DO4``
    `` Do4 do4 mi4 sol4```
    `` Do4 do4 mi4 sol4```
    `` Do5 re5 do5 si4 la4 sol4 fa4 ''`

    La durada de les notes serà de 200, 400 o 800 mil·lisegons.
