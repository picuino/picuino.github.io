3. Exercicis amb LED, parpellejar¶

Programa els blocs necessaris per resoldre els problemes següents.

  1. Copieu el programa per obtenir el parpelleig del LED D1 del tauler de control Picuino.

  2. Simulació de balises. Copieu el programa per obtenir el parpelleig alternatiu dels LED D1 i LED D4 de la placa de control de Picuino.

  3. Simulador d’alarma. Feu un programa que encengui el LED D1 durant una desena part cada 3 segons.

  4. Simulador d’arbres de Nadal. Feu un programa que encengui el D1 A D6 amb diferents moments d’encesa i desactiveu cadascun.

  5. Fletxa tipus 1. Copieu el programa per obtenir el parpelleig del D1 A D6 que simula una fletxa que es dirigeix ​​a la dreta i s’apaga a la dreta.

  6. Completeu el programa anterior perquè LED D4, D5 i D6 també s’encenguin.

  7. Arrow Type 2. Copieu el programa per obtenir el parpelleig de Ledes D1 A D6 que simula una fletxa que es dirigeix ​​a la dreta i s’apaga a l’esquerra.

  8. Completeu el programa anterior perquè LED D4, D5 i D6 també s’encenguin.
