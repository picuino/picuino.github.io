24. Resum de l'etiqueta HTML¶

Etiquetes bàsiques¶

`` <! Doctype html>`
Etiqueta inicial que informa al navegador que a continuació ve un document de tipus HTML.
`` <html> </html>`
Etiqueta inicial i final de tots els documents de tipus HTML.
`` <head> </nad>`
Secció de capçalera del document. Aquesta secció defineix el títol de la pàgina, estils, etc.
`` <title> </title>`
Títol de la pàgina HTML. Ha d’aparèixer a la secció <now>.
`` <E Body
Cos del document. En aquesta secció hi haurà tots els continguts que apareixen al lloc web. Textos, imatges, llistes, taules, etc.
`` <!-Comentari-> ''
Aquesta etiqueta és un comentari que no es veurà al navegador. Serveix per comentar per aclarir el contingut HTML i facilitar la seva comprensió.

Plantilla de document HTML.

<!doctype html>
<html>

<!-- Cabecera -->
<head>
   <title> </title>
</head>

<!-- Cuerpo -->
<body>

</body>

</html>

Etiquetes de contingut¶

`` <p> </p>`
Etiqueta de paràgraf. Engloba un paràgraf de text amb diverses frases consecutives. Acaben en un punt i a part.
`` <h1> </h1>`
Encapçalament de primer nivell. És equivalent a un títol de capítol.
`` <h2> </h2>`
Encapçalament de segon nivell. Equival a un títol de secció.
`` <h3> </h3>`
Encapçalament de tercer nivell. És equivalent a un títol de subsecció.
`` <h4> </h4>`
Encapçalament del quart nivell.

Salt de línia¶

`` `'
Salt de línia. El que s’escriu a continuació apareixerà a la línia següent del navegador.
`` <hr>`
Línia de separació horitzontal.

Tipus de text¶

`` <em> </em>`
Text destacat amb èmfasi. El tipus de lletra serà *italic *.
`` <strong> </strong>`
Text important amb un fort èmfasi. El tipus de lletra serà ** negreta **.
`` <cite> </cite>`
El text interior és una cita d’una altra font o d’un altre autor.
`` <blockquote cite = "http: // "> </blockquote> `
Etiqueta que inclou una secció de text que s'ha copiat des d'una altra pàgina. L’etiqueta BlockQuote conté un atribut CITE que descriu l’adreça de la qual s’ha pres el text. Normalment, aquesta secció apareix desplaçada a la dreta.
`` <st> </st>`
Etiqueta de text preformat. Es conserven tots els espais i línies. La font utilitzada és fixa (monospaced).
`` <code> </coe>`
Etiqueta per incloure el codi de l'ordinador. El tipus de lletra es fixarà en ampli.

Hiperenllaços, imatges i objectes¶

`` <a href = "salt "> text </a> ``
Hiperenllaç. El text entre les etiquetes apareixerà al navegador. En fer clic al text, saltarà a la referència que conté HREF.
`` <img src = "imatge ">`
Enllaç a una imatge que s’inserirà al document.
`` <Objecte data = ""> </bject>`
Aquesta etiqueta insereix a la pàgina HTML un element extern que pot ser un fitxer de text, un vídeo, sons, una pàgina web, etc. El nom i la ruta de l'objecte s'escriuen dins de l'atribut de dades.
`` id = "nom "`
Aquest atribut apareix dins d’una etiqueta per donar -la. El nom ha de ser únic i no repetir, per distingir les etiquetes les unes de les altres.

Llistes i definicions¶

`` <i> </l>`
Etiqueta de llista numerada.
`` <ul></ul>`
Etiqueta de llista no nombrada.
`` <li> </li>`
Etiqueta que conté un element de la llista.
`` <dl> </dl>`
Etiqueta de definició de paraules.
`` <dt> </dt>`
Paraula que s'ha de definir.
`` <dd> </dd>`
Definició d'una paraula.

Taules de dades¶

`` <bable> </bable>`
Etiqueta de taula.
`` <str> </r>`
Etiqueta una fila dins d’una taula.
`` <sad> </sad>`
Etiqueta l’encapçalament d’una taula. Es troba a la primera fila d’una taula.
`` <th> </th>`
Etiqueta cadascun dels elements d'una capçalera de taula.
`` <body> </body>`
Cos d’una taula, on es troba el contingut de la taula. Permet separar la capçalera del contingut.
`` <td> </td>`
Etiqueta un element d’una taula. Ha d’estar dins d’una fila.
`` <Td rowspan = 2>`
Aquest atribut apareix dins d’un element de taula <td>. Permet unir -se a la cel·la actual amb les cèl·lules de la dreta de la mateixa fila, per fer una sola cel·la més gran.
`` <td colSpan = 2>`
Aquest atribut apareix dins d’un element de taula <td>. Permet unir -se a la cel·la actual amb les cel·les per sota de la mateixa columna, per fer una sola cel·la més gran.

Taula de dades sense cap.

<table border="1">
   <tbody>
      <tr>
         <td>Uno</td>  <td> 1 </td>
      </tr>
      <tr>
         <td>Dos</td>  <td> 2 </td>
      </tr>
   </tbody>
</table>
