13. Logotip de monoqoool¶

; BR |

  1. Obrim un nou document amb Inkscape.

    ; BR |

  2. Amb el text de l'eina d'escriptura | Text de botons | Escrivim la paraula "monoqoool " amb l'agència Fuente FB, estil tipogràfic condensat, mida de 64 punts i distància entre lletres 0.

    ; BR |

  3. Amb l’eina de selecció | Selecció de botons | Estem estirant el text horitzontalment fins a les lletres o més quadrats.

    ; BR |

  4. Doblem el text amb les tecles Control+D, el reflectim verticalment amb el `` Menú d'objectes ... Reflex vertical '' i movem el text invertit sota el primer text ajustant la seva posició exactament amb el menú `` objecte ... alinear i distribuir ''.

    ; BR |

  5. Per continuar, dibuixarem un rectangle que ocupi aproximadament la mateixa mida que el text següent.

    El rectangle ha de tenir un lineal degradat amb color negre i gairebé blanc, sense transparència.

    Aquest rectangle servirà de màscara per degradar el color del text. Les zones més blanques deixaran el text de color més fosc i els negres deixaran el text més clar, gairebé incapaç de ser vist.

    ; BR |

  6. Seleccionem el text anterior i el rectangle i alineem els dos objectes.

    Tornem a ajustar la mida vertical de manera que la mida del text s’il·lumini el màxim possible.

    ; BR |

  7. Ara seleccionem el rectangle i el text següent i seleccionem el funcionament del menú `` objecte ... màscara ... aplica ''.

    Ja hem aconseguit un efecte de reflexió del text.

    ; BR |

  8. Per fer la reflexió més subtil, seleccionarem el text següent i a l’objecte `` ... Emplenament i vores ... `` A les opcions d'ompliment canviarem la transparència a 50.

    I ja tenim el logotip acabat.
