5. Els comentaris¶

Els comentaris són textos que ajuden a explicar el funcionament d’un programa. L’intèrpret de Python ignora els comentaris, només serveixen per ajudar el programador, però no tenen funcionalitat.

A Python els comentaris comencen amb el `` ``

>>> 5  # Esto es un número entero. Este comentario se ignora.
    5
>>> # Esto es un comentario. El intérprete lo ignora.
>>>

Heu d’intentar que el codi expliqui sol, gràcies als noms explicatius i gràcies a una bona organització del codi. Els comentaris només s’han d’utilitzar en ocasions excepcionals, quan cal afegir alguna explicació al codi que no es pot fer d’una altra manera.
