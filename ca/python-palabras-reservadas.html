4. Paraules reservades¶

Les paraules reservades d’un llenguatge de programació són un conjunt de paraules que tenen un significat especial i que es reserven per utilitzar -se per al llenguatge. Cadascuna d’aquestes paraules té un propòsit específic i no es pot utilitzar com a noms de variables o com a noms de funcions.

Aquestes són les 33 paraules reservades a Python:

  • `Fals
  • Cap
  • True
  • i
  • Com
  • Assert
  • "Break <https://www.w3schools.com/python/ref_keyword_break.asp>`__
  • Classe
  • `Continua <https://www.w3schools.com/python/ref_keyword_continue.asp>
  • Def
  • de
  • Elif
  • Else
  • Excepte
  • Finalment

  • Mentre que
  • amb
  • Produir

Quan el codi s’escriu amb un editor amb ** ressaltat de la sintaxi ** Les paraules reservades es coloren per distingir -les de la resta. Per exemple, a l’editor oci de Python, va reservar les paraules Colo amb taronja.

Superior i minúscula¶

Es diu que les paraules de Python són ** sensibles al cas **, cosa que significa que són diferents si estan escrites en majúscules escrites en minúscules.

D’aquesta manera, la paraula “falsa” serà diferent de la paraula `fals”. Heu de tenir en compte això per no equivocar -vos quan escriviu la paraula correcta, que és "falsa".

Heu d’evitar utilitzar aquesta funció Python per anomenar dues variables diferents amb el mateix nom, una de majúscules i una altra en minúscules. El resultat seria vàlid i funcionaria com a dues variables diferents, però no s’hauria de programar d’aquesta manera perquè pot provocar fallades difícils.

variable = 3

# Esta una variable diferente
Variable = 5

# No se deben nombrar variables tan semejantes
